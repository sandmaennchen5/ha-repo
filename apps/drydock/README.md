Drydock als Home-Assistant-App mit Ingress, persistentem Speicher und Zugriff auf
die lokale Docker Engine. Die Oberfläche überwacht Image-Updates, Benachrichtigungen,
Audit-Ereignisse und konfigurierbare Update-Aktionen.

## Installation

Füge `https://github.com/sandmaennchen5/ha-repo` als App-Repository hinzu,
installiere **Drydock** und öffne anschließend die Weboberfläche.

Weitere Hinweise stehen in [DOCS.md](DOCS.md).

- [Drydock-Dokumentation](https://getdrydock.com/docs/)
- [Upstream-Repository](https://github.com/CodeSWhat/drydock)
