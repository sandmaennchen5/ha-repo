# Drydock Home Assistant App

<!-- BADGES-START -->
<!-- BADGES-END -->

Drydock packaged as a Home Assistant app with Ingress, persistent storage and
access to the local Docker engine. Its UI monitors image updates, notifications,
audit events and configurable update actions.

Add `https://github.com/sandmaennchen5/ha-repo` as an app repository, install
**Drydock**, then open its Web UI. See [DOCS.en.md](DOCS.en.md) for details.

- [Drydock documentation](https://getdrydock.com/docs/)
- [Upstream repository](https://github.com/CodeSWhat/drydock)
